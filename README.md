# Вулик.Маркет, final production UI

## Запуск у Windows PowerShell

```powershell
npm install
npm run typecheck
npm run build
npm run dev
```

## У цій версії є

- перший прополісний дизайн із медовим акцентом;
- адаптивна шапка, mobile menu і каталог для телефонів;
- пошук, категорії, фільтр наявності;
- сторінка товару з кількістю, обраним, кошиком, доставкою і відгуками;
- форма додавання відгуку з оцінкою, валідацією і success state;
- реєстрація з email, телефоном, умовами, показом пароля та перевіркою підтвердження;
- login, кабінет, замовлення, обране, кошик, checkout, продавець і FAQ;
- localStorage без перезапису даних до hydration;
- код у нормальному форматуванні з відступами;
- `useSearchParams` обгорнутий у Suspense.

Backend для реальної авторизації, платежів, замовлень, server-side валідації і storage фото підключається окремо.
