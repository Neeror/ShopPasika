# Вулик.Маркет — фронтенд-правки

Розпакуйте архів і скопіюйте вміст папки `ShopPasika-fix` у корінь репозиторію
з перезаписом. Структура папок уже збігається з проєктом.

## Додана правка

`app/seller/add/page.tsx` тепер публікує оголошення одразу після відправки форми:

- замість «відправлено на перевірку» показується «оголошення опубліковано одразу»;
- одразу показується готова картка товару через існуючий `ProductCard`;
- можна відкрити картку товару або додати ще одне оголошення;
- дані оголошення зберігаються в `localStorage` під ключем `pasika-published-listings`;
- фото та опис використовуються в опублікованій картці без додаткового очікування;
- інші екрани й функції не змінені.

## Попередні правки в архіві

Усередині також залишені всі файли з попереднього архіву: чат із продавцем,
відгуки без модерації, картка продавця та зміни шапки.

Після копіювання:

```powershell
npm run typecheck
npm run build
```
