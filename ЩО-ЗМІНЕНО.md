# Вулик.Маркет — фронтенд: «Написати продавцю» + технічна підтримка

Розпакуйте архів у корінь проєкту ShopPasika (з заміною файлів), потім:

```powershell
npm install
npm run typecheck
npm run build
npm run dev
```

Бекенд не потрібен: усе працює на клієнті через localStorage, тож пізніше
достатньо буде замінити запис у localStorage на виклики API.

## Де тепер є «Написати продавцю»

1. Картка товару в каталозі (іконка поруч з кнопкою кошика).
2. Сторінка товару — великий блок продавця та блок під відгуками.
3. Профіль продавця `/seller/<slug>` — головна кнопка в сайдбарі.
4. Кабінет → «Повідомлення продавцям» — кнопка «Написати ще».

Всі повідомлення пишуться у localStorage (`pasika-seller-messages`),
звернення в підтримку — у `pasika-support-tickets`, чат — у `pasika-support-chat`.
